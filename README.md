## Background updates

Allow Obtainium to install apps, keep its background checks and updates enabled, and install Radio through Obtainium once. Android may delay background work or request confirmation depending on OS permissions. No GitHub login, VPN, NAS connection or Radio service credentials are required to download updates.

Profiles select the correct APK flavor and pin the established signing certificate. Each release includes SHA-256 checksums and a release manifest. Updates preserve the package and signing identity.
